# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues in `GCherry/teach`. Use the `gh` CLI or configured GitHub MCP tools.

## Issue Lifecycle & Hygiene (Required when working an issue)

1. **Claim & Kickoff:**
   - Assign to `@GCherry`.
   - Apply `work-started`.
   - Post a kickoff comment naming the plan path (`plans/<slug>.md`), target branch (`feature/<slug>` or `fix/<slug>`), and locked scope.
2. **In-Flight Progress:**
   - Sync `- [x]` checkboxes as criteria are verified.
   - Post concise milestone comments when waves complete or PRs open.
3. **Pull Request & Closure:**
   - Include `Closes #<number>` in the PR body.
   - Ensure all checkboxes are ticked and archive completed plans to `plans/archive/<slug>.md`.

## Pull requests as a triage surface

**PRs as a request surface: no.**
