The Six-Plane AI Software Factory Blueprint

Compressed architecture reference mapping chill-hq's workflow control plane to an agnostic AI Gateway, dual-path observability pipeline, and leadership governance model. Pair with Lesson 0001: The Agnostic Control Plane.

1. The Six Planes (chill-hq vs. Enterprise Pitch)

Plane Core Responsibility chill-hq Today chill-hq Upgrade Gap Enterprise Pitch Equivalent
1. Intake & Context Turn raw issues/specs into agent-ready contracts & vocabulary. AGENTS.md, GLOSSARY.md, docs/adr/, Planner + real-work plans, repo onboarding guide. Automate readiness scorecards & inject attribution tags (issue, risk_tier) at dispatch. Ticket triage gate (ready-for-agent), standardized repo steering files.
2. Execution & Sandbox Run interactive IDEs/CLIs or isolated background agents safely. Interactive harnesses (Antigravity now, Claude Code planned), git worktrees, Narrowing Gate cap. Headless container/worktree runner template with max-retry circuit breaker & credit cap per run. Ephemeral cloud devboxes ("cattle, not pets", e.g., Stripe Minions EC2 devboxes).
3. Toolshed (MCP & Data) Provide least-privilege tools, docs, and code search to agents. GitHub MCP, CLI tools (gh), shared .agents/skills/ single source of truth. Read-only tool allowlists per Role + secret scrubbing before telemetry emission. Central governed MCP Gateway (read-only DB/logs, prompt-injection filters).
4. AI Gateway & FinOps Virtual keys, model routing (cloud + local), budgets, prompt caching. Missing. Harnesses connect directly using user subscriptions or local config. Issue target: Role-based model routing table + local LiteLLM/OpenAI-compat gateway profile. SSO-bound Virtual Keys, rolling USD credit caps, graceful tier fallback, prompt-cache enforcement.
5. Verification & Release Prevent bad code from shipping via independent checks & Merge Bar. bin/validate.py, independent Reviewer (Standards + Spec), Acceptance Check, 4-part Merge Bar. Include model/role cost summary & verification pass rates inside PR/Retro artifacts. Deterministic CI + AI-as-judge PR gate + human final merge accountability.
6. Observability & Intelligence Join token/credit spend with PR throughput & quality metrics. Raw local logs (transcript.jsonl) & Retro reviews, but no unified metrics store. Issue target: Emit canonical factory_event/v1 spans from Gateway + Collector hooks; join with gh PR data. Executive dashboard: DAU, Spend, Cost/Merged PR, Cycle Time, 14-day Churn & Revert Rate.

2. Dual-Path Agnostic Ingestion Pattern

Path 1 · Gateway Proxy

Metered Cloud APIs & Local Models

Covers CI agents, automated PR reviewers, custom scripts, and local inference servers (Ollama / vLLM) plus pay-as-you-go Anthropic, OpenAI, or Vertex keys.

  • Control Point: OpenAI/Anthropic-compatible proxy (e.g., LiteLLM Proxy).
  • Limits: Virtual Key per user/agent role with rolling max_budget (USD credits) + TPM/RPM caps.
  • Attribution: Custom HTTP headers (x-factory-role, x-factory-repo, x-factory-branch).
Path 2 · Harness Collector

Flat-Rate Subscription Harnesses

Covers Google Antigravity and Claude Code Pro/Max seats authenticated via OAuth, which cannot be blindly rerouted through a metered third-party API proxy.

  • Control Point: Harness-native limits (seat quotas) + local OTel/transcript collector hook.
  • Claude Code: Enable CLAUDE_CODE_ENABLE_TELEMETRY=1 + OTLP exporter.
  • Antigravity / Others: Post-session / Retro parser reading transcript.jsonl + git context.

4. Three-Tier Leadership Metrics Cheat Sheet

Tier Core Metrics Formula / Signal What It Catches
1. Input & Adoption DAU/WAU by harness, Cache Hit Ratio, Credit Utilization cached_tokens / total_input_tokens Shelfware licenses vs. real usage; misconfigured prompt caching burning budget.
2. Factory Throughput Merged PRs/Engineer/Week, Agent-Authored PR Share, Cycle Time merged_prs(ai_attributed) / active_devs Raw delivery velocity and which tasks (bugs vs. features) succeed in the factory.
3. Quality Guardrails Cost per Merged PR, Review Rounds, Revert Rate, 14-Day Churn sum(estimated_cost_usd) / count(merged_prs) The "AI Productivity Paradox": high PR volume masking review gridlock or broken merges.
