Reference 0001 · Printable Architecture Comparison & Primitives Map

MCP vs. HTTP REST+SSE vs. CLI (Anchored in ytmix)

Side-by-side protocol reference comparing all three interfaces over GCherry/ytmix's internal/mixer engine. Pair with Lesson 0001: Why MCP Is Not Just Another API.

1. Interface Comparison Matrix

Dimension CLI (cmd/ytmix/main.go) HTTP REST+SSE (internal/ui/server.go) MCP Stdio (internal/mcp/server.go)
Primary Caller Human in shell, CI scripts, or bash-enabled coding agents. Dedicated web SPA (ytmix ui browser frontend). Any MCP Host (Antigravity, Claude Desktop, Cursor, custom agents).
Transport & Framing Process args + stdout/stderr + exit code. HTTP/1.1 JSON + Server-Sent Events + binary downloads. Newline-delimited JSON-RPC 2.0 over stdin/stdout (16 MiB cap; diagnostics on stderr).
Discovery --help text (parsed ad hoc). None at runtime (client hardcoded routes at build time). Formal handshake: initialize → tools/list, resources/list, prompts/list.
Session State Stateless one-shot invocation. Stateless HTTP requests + server job store. 1:1 stateful subprocess session per Host Client.
Long-Running Progress Live terminal stdout progress lines. Push stream via GET /api/render/{id}/events (SSE). Poll get_render_status or read ytmix://jobs/{id}.
Safety & Consent Signals Interactive prompts or dry-run flags. UI button confirmation inside web app. ToolAnnotations hints + separate plan_mix dry-run + server-side validation.

2. Complete ytmix MCP Primitives Inventory

Tools · Model-Controlled (9)

Executable Actions (tools/call)

  • get_capabilities — FFmpeg/FFprobe, encoders, presets (ReadOnlyHint: true).
  • inspect_tracks — Audio durations, rawId3Title vs. displayTitle, warnings.
  • inspect_background — Image/video dimensions, 16:9 check, stray audio flag.
  • plan_mix — Zero-write dry-run: rendering path, ETA, YouTube Chapter Timestamps (ReadOnlyHint: true).
  • preview_visualizer_frame — Single-frame Path D visualizer PNG preview.
  • start_render — Launches async render goroutine; returns jobId (ReadOnlyHint: false).
  • get_render_status — Polls step, progress %, speed, ETA.
  • cancel_render — Context-cancels an active render job (IdempotentHint: true).
  • verify_mix — Probes output .mp4 H.264/AAC streams and timestamps.txt.
Resources & Prompts · Host & User

Context & Workflows

Static Resources (resources/read, Host-controlled):

  • ytmix://presets — 14 Path D Auto Visualizer presets + live filter status.
  • ytmix://themes — 7 Path D Color Themes.
  • ytmix://resolutions — 1080p, 1440p, 4k specs.

Dynamic Job Resources:

  • ytmix://jobs/{id} — Live JSON job snapshot.
  • ytmix://jobs/{id}/timestamps — Generated timestamps.txt text (verified separately via verify_mix).

Prompts (prompts/get, User-controlled):

  • create-sleep-mix (audioDir, targetDuration)
  • clean-youtube-release (audioDir, bgPath)
